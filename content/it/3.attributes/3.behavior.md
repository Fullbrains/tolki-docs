## `default-open`

Se impostato, la finestra di chat si apre automaticamente al caricamento della pagina.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `boolean` |
| **Default** | `true` |

```html
<!-- Chat aperta al caricamento -->
<tolki-chat bot="..." default-open></tolki-chat>
<tolki-chat bot="..." default-open="true"></tolki-chat>

<!-- Chat chiusa al caricamento -->
<tolki-chat bot="..." default-open="false"></tolki-chat>
```

## `expandable`

Permette all'utente di espandere la finestra di chat a schermo intero.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `boolean` |
| **Default** | `true` |

```html
<!-- Espansione abilitata (default) -->
<tolki-chat bot="..." expandable></tolki-chat>

<!-- Espansione disabilitata -->
<tolki-chat bot="..." expandable="false"></tolki-chat>
```

## `show-rating`

Mostra un prompt di valutazione della conversazione (1–5 stelle) dopo un periodo di inattività successivo a una risposta dell'assistente. La valutazione viene mostrata una sola volta per sessione di chat.

Accetta `true` (ritardo predefinito di 90 secondi), `false` (disabilitato) o un numero di secondi per un ritardo personalizzato.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `boolean \| number` |
| **Default** | `true` (90 secondi) |

```html
<!-- Valutazione abilitata con ritardo predefinito (90s) -->
<tolki-chat bot="..." show-rating></tolki-chat>

<!-- Valutazione disabilitata -->
<tolki-chat bot="..." show-rating="false"></tolki-chat>

<!-- Ritardo personalizzato: 30 secondi -->
<tolki-chat bot="..." show-rating="30"></tolki-chat>
```

## `show-sources`

Se attivato, la toolbar dell'assistente mostra un pulsante "Fonti" che apre una sidebar con i risultati della ricerca documentale usati per generare la risposta. La sidebar appare sul lato opposto del widget di chat.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `boolean` |
| **Default** | `false` |

```html
<!-- Mostra le fonti documentali -->
<tolki-chat bot="..." show-sources></tolki-chat>

<!-- Nascondi le fonti documentali (default) -->
<tolki-chat bot="..." show-sources="false"></tolki-chat>
```

::callout{icon="i-lucide-info"}
Questo attributo è abilitato automaticamente su `localhost` e `studio.tolki.ai`.
::

## `show-queries`

Se attivato, la sidebar delle fonti mostra informazioni di debug aggiuntive per ogni ricerca: il testo della query, l'ID di ricerca della query e l'ID di ricerca dei risultati.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `boolean` |
| **Default** | `false` |

```html
<!-- Mostra info di debug nella sidebar fonti -->
<tolki-chat bot="..." show-sources show-queries></tolki-chat>
```

::callout{icon="i-lucide-info"}
Richiede che `show-sources` sia abilitato affinché la sidebar appaia. Questo è un attributo di debug.
::

## `unclosable`

Se attivato, l'utente non può chiudere la finestra di chat. Utile per widget inline o quando la chat deve rimanere sempre visibile.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `boolean` |
| **Default** | `false` |

```html
<!-- La chat non può essere chiusa -->
<tolki-chat bot="..." unclosable></tolki-chat>

<!-- Comportamento standard (chiudibile) -->
<tolki-chat bot="..." unclosable="false"></tolki-chat>
```
