Tutti gli attributi testuali supportano l'internazionalizzazione. Consulta [Internazionalizzazione](/it/embed/i18n) per i dettagli sui formati.

## `name`

Nome del bot visualizzato nell'header della finestra di chat.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string` \| `I18nString` |
| **Default** | `''` |

```html
<tolki-chat bot="..." name="Assistente Tolki"></tolki-chat>
<tolki-chat bot="..." name='{"en":"Assistant","it":"Assistente"}'></tolki-chat>
<tolki-chat bot="..." name="en:Assistant|it:Assistente"></tolki-chat>
```

## `message-placeholder`

Testo placeholder mostrato nell'area di input quando è vuota.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string` \| `I18nString` |
| **Default** | Multilingua: "Ask anything" / "Chiedi qualsiasi cosa" / ecc. |

```html
<tolki-chat bot="..." message-placeholder="Scrivi un messaggio..."></tolki-chat>
<tolki-chat bot="..." message-placeholder='{"en":"Type a message...","it":"Scrivi un messaggio..."}'></tolki-chat>
<tolki-chat bot="..." message-placeholder="en:Type a message...|it:Scrivi un messaggio..."></tolki-chat>
```

## `toggle-placeholder`

Testo mostrato accanto al pulsante toggle (utile per aggiungere un'etichetta al pulsante di apertura).

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string` \| `I18nString` |
| **Default** | `''` (nessun testo) |

```html
<tolki-chat bot="..." toggle-placeholder="Hai bisogno di aiuto?"></tolki-chat>
<tolki-chat bot="..." toggle-placeholder="en:Need help?|it:Hai bisogno di aiuto?"></tolki-chat>
```

## `welcome-message`

Messaggio di benvenuto mostrato all'apertura della chat, prima che l'utente scriva qualcosa.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string` \| `I18nString` |
| **Default** | `null` (nessun messaggio) |

```html
<tolki-chat bot="..." welcome-message="Ciao! Come posso aiutarti?"></tolki-chat>
<tolki-chat bot="..." welcome-message='{"en":"Hi! How can I help?","it":"Ciao! Come posso aiutarti?"}'></tolki-chat>
<tolki-chat bot="..." welcome-message="en:Hi! How can I help?|it:Ciao! Come posso aiutarti?"></tolki-chat>
```

## `suggestions`

Lista di suggerimenti rapidi mostrati sotto il messaggio di benvenuto. L'utente può cliccarli per inviare velocemente un messaggio predefinito.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string[]` \| `I18nArray` |
| **Default** | `[]` (nessun suggerimento) |

```html
<tolki-chat bot="..." suggestions="Prezzi,Assistenza,Contatti"></tolki-chat>
<tolki-chat bot="..." suggestions='["Quanto costa?","Come funziona?","Contattaci"]'></tolki-chat>
<tolki-chat bot="..." suggestions='[{"en":"Pricing","it":"Prezzi"},{"en":"Support","it":"Assistenza"}]'></tolki-chat>
<tolki-chat bot="..." suggestions="en:Pricing|it:Prezzi,en:Support|it:Assistenza"></tolki-chat>
```

## `toasts`

Lista di messaggi toast mostrati come notifiche temporanee.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string[]` \| `I18nArray` |
| **Default** | `[]` (nessun toast) |

I formati supportati sono gli stessi di `suggestions`.

```html
<tolki-chat bot="..." toasts="Benvenuto!,Hai bisogno di aiuto?"></tolki-chat>
<tolki-chat bot="..." toasts='[{"en":"Welcome!","it":"Benvenuto!"}]'></tolki-chat>
```
