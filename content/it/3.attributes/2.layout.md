## `position`

Posizionamento del widget nella pagina.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `'inline'` \| `'left'` \| `'center'` \| `'right'` |
| **Default** | `'right'` |

- `right` — Angolo in basso a destra (posizione classica per chat widget)
- `left` — Angolo in basso a sinistra
- `center` — In basso al centro
- `inline` — Incorporato direttamente nel flusso della pagina (senza pulsante)

```html
<tolki-chat bot="..." position="right"></tolki-chat>
<tolki-chat bot="..." position="left"></tolki-chat>
<tolki-chat bot="..." position="center"></tolki-chat>
<tolki-chat bot="..." position="inline"></tolki-chat>
```

## `window-size`

Dimensione della finestra di chat quando è aperta.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `'sm'` \| `'md'` \| `'lg'` \| `'xl'` |
| **Default** | `'sm'` |

```html
<tolki-chat bot="..." window-size="sm"></tolki-chat>
<tolki-chat bot="..." window-size="md"></tolki-chat>
<tolki-chat bot="..." window-size="lg"></tolki-chat>
<tolki-chat bot="..." window-size="xl"></tolki-chat>
```

## `toggle-size`

Dimensione del pulsante circolare che apre/chiude la chat.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `'sm'` \| `'md'` \| `'lg'` |
| **Default** | `'md'` |

```html
<tolki-chat bot="..." toggle-size="sm"></tolki-chat>
<tolki-chat bot="..." toggle-size="md"></tolki-chat>
<tolki-chat bot="..." toggle-size="lg"></tolki-chat>
```

## `margin`

Margine del widget rispetto ai bordi della pagina, in pixel. Supporta un valore singolo o due valori per gli assi X e Y.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `number` \| `[number, number]` |
| **Default** | `20` |

**Formati supportati:**
- Numero singolo: `"20"` — margine uguale su tutti i lati
- Separato da virgola: `"20,30"` — X=20px, Y=30px
- Array JSON: `"[20,30]"` — X=20px, Y=30px

```html
<tolki-chat bot="..." margin="20"></tolki-chat>
<tolki-chat bot="..." margin="10,30"></tolki-chat>
<tolki-chat bot="..." margin="[15,25]"></tolki-chat>
<tolki-chat bot="..." margin="0"></tolki-chat>
```

## `window-max-height`

Altezza massima della finestra di chat. Accetta qualsiasi valore CSS valido.

| Proprietà | Valore |
|-----------|--------|
| **Tipo** | `string` |
| **Default** | `'728px'` |

```html
<!-- Altezza massima predefinita -->
<tolki-chat bot="..." window-max-height="728px"></tolki-chat>

<!-- Percentuale del contenitore -->
<tolki-chat bot="..." window-max-height="50%"></tolki-chat>

<!-- Relativo al viewport -->
<tolki-chat bot="..." window-max-height="90vh"></tolki-chat>

<!-- Valore calcolato -->
<tolki-chat bot="..." window-max-height="calc(100vh - 50px)"></tolki-chat>
```

::callout{icon="i-lucide-info"}
Questo si applica solo alla finestra flottante su desktop (≥480px). Su mobile, la chat si apre sempre a schermo intero.
::
