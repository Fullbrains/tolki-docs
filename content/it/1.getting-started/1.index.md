Tolki Embed è un **web component** costruito con Lit Element che fornisce un'interfaccia chat incorporabile. Si connette al backend Tolki AI per offrire esperienze conversazionali intelligenti su qualsiasi sito web.

## Funzionalità principali

- **Integrazione con un tag** — Aggiungi `<tolki-chat>` al tuo HTML e hai finito
- **Zero dipendenze** — Distribuito come bundle IIFE autonomo
- **Shadow DOM** — Stili completamente incapsulati, nessun conflitto CSS
- **27 attributi HTML** — Controllo totale su aspetto e comportamento
- **Multilingua** — Supporto integrato per EN, IT, ES, FR, DE, PT
- **Modalità scura** — Automatica, chiara o scura
- **Responsive** — Mobile-first con rilevamento della tastiera virtuale
- **Cronologia chat** — Persistente per istanza del bot in localStorage

## Come funziona

Il widget si carica come un singolo file JavaScript e registra un custom element `<tolki-chat>`. Quando fornisci un UUID `bot`, recupera la configurazione del bot dall'API Tolki e mostra l'interfaccia chat.

```html
<!-- 1. Carica lo script -->
<script src="https://embed.tolki.ai/chat.js" defer></script>

<!-- 2. Aggiungi il componente -->
<tolki-chat bot="YOUR-BOT-UUID"></tolki-chat>
```

Il componente supporta un **sistema di priorità** per la configurazione:

1. **Attributi HTML** (priorità massima) — Valori impostati direttamente nel tag
2. **Backend** — Valori dall'API Tolki in base alla configurazione del bot
3. **Default** (priorità minima) — Valori di fallback predefiniti

Questo significa che puoi personalizzare tutto lato client tramite attributi HTML, e la configurazione del backend funge da base.
