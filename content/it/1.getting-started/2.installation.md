## Script Tag

Il modo più semplice per aggiungere Tolki Chat a qualsiasi sito web. Basta aggiungere il tag script prima della chiusura del tag `</body>`.

```html
<script src="https://embed.tolki.ai/chat.js" defer></script>
```

Poi posiziona il componente `<tolki-chat>` ovunque nella tua pagina:

```html
<tolki-chat bot="YOUR-BOT-UUID"></tolki-chat>
```

::callout{icon="i-lucide-info"}
Sostituisci `YOUR-BOT-UUID` con l'UUID fornito nella tua dashboard Tolki.
::

## Esempio completo

```html
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Il mio sito</title>
</head>
<body>

  <h1>Benvenuto nel mio sito</h1>

  <!-- Widget Tolki Chat -->
  <script src="https://embed.tolki.ai/chat.js" defer></script>
  <tolki-chat
    bot="YOUR-BOT-UUID"
    position="right"
    theme="auto"
    lang="it"
  ></tolki-chat>

</body>
</html>
```

## WordPress

Incolla il seguente snippet nel `footer.php` del tuo tema o usa un plugin come **Insert Headers and Footers**:

```html
<script src="https://embed.tolki.ai/chat.js" defer></script>
<tolki-chat bot="YOUR-BOT-UUID"></tolki-chat>
```

## Shopify

Vai su **Negozio online > Temi > Modifica codice** e aggiungi lo snippet prima di `</body>` in `theme.liquid`:

```html
<script src="https://embed.tolki.ai/chat.js" defer></script>
<tolki-chat bot="YOUR-BOT-UUID"></tolki-chat>
```

## Single Page Application

Essendo `<tolki-chat>` un web component standard, funziona con qualsiasi framework SPA. Basta aggiungerlo al template root o al layout.

### React

```jsx
function App() {
  return (
    <div>
      <h1>La mia app</h1>
      <tolki-chat bot="YOUR-BOT-UUID" />
    </div>
  )
}
```

### Vue

```vue
<template>
  <div>
    <h1>La mia app</h1>
    <tolki-chat bot="YOUR-BOT-UUID" />
  </div>
</template>
```

### Angular

Aggiungi `CUSTOM_ELEMENTS_SCHEMA` al tuo modulo, poi usa il tag direttamente:

```html
<tolki-chat bot="YOUR-BOT-UUID"></tolki-chat>
```
