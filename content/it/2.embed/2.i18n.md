Tolki Chat ha supporto integrato per 6 lingue: **inglese**, **italiano**, **spagnolo**, **francese**, **tedesco** e **portoghese**.

## Impostare la lingua

Usa l'attributo `lang` per impostare la lingua dell'interfaccia:

```html
<tolki-chat bot="..." lang="it"></tolki-chat>
```

L'attributo `lang` è **bidirezionale**: può essere impostato via HTML e viene aggiornato automaticamente quando l'utente cambia lingua dalla chat.

## Limitare le lingue disponibili

Usa l'attributo `locales` per restringere il selettore lingua:

```html
<!-- Solo italiano e inglese -->
<tolki-chat bot="..." locales="en,it"></tolki-chat>
```

## Attributi testuali multilingua

Gli attributi testuali come `name`, `message-placeholder`, `welcome-message`, `toggle-placeholder`, `suggestions` e `toasts` supportano l'internazionalizzazione. Ci sono tre formati:

### Stringa semplice

Una singola stringa usata per tutte le lingue:

```html
<tolki-chat bot="..." name="Assistente"></tolki-chat>
```

### Formato JSON

Un oggetto JSON con chiavi per lingua:

```html
<tolki-chat
  bot="..."
  name='{"en":"Assistant","it":"Assistente","es":"Asistente"}'
></tolki-chat>
```

### Formato pipe

Un formato compatto che usa coppie `lingua:valore` separate da `|`:

```html
<tolki-chat
  bot="..."
  name="en:Assistant|it:Assistente|es:Asistente"
></tolki-chat>
```

## Array multilingua

Gli attributi come `suggestions` e `toasts` accettano array con supporto i18n:

### Separati da virgola

```html
<tolki-chat bot="..." suggestions="Prezzi,Assistenza,Contatti"></tolki-chat>
```

### Array JSON i18n

```html
<tolki-chat
  bot="..."
  suggestions='[{"en":"Pricing","it":"Prezzi"},{"en":"Support","it":"Assistenza"}]'
></tolki-chat>
```

### Formato pipe (separato da virgola)

```html
<tolki-chat
  bot="..."
  suggestions="en:Pricing|it:Prezzi,en:Support|it:Assistenza"
></tolki-chat>
```
