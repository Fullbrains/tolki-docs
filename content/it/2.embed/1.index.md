Il widget `<tolki-chat>` è un web component autonomo che mostra un'interfaccia chat flottante sul tuo sito web. Gestisce tutto, dal pulsante di apertura alla persistenza della cronologia messaggi.

## Modalità di visualizzazione

### Widget flottante

Per impostazione predefinita, il widget appare come un pulsante flottante in un angolo della pagina. Cliccandolo si apre la finestra di chat.

```html
<!-- In basso a destra (default) -->
<tolki-chat bot="..." position="right"></tolki-chat>

<!-- In basso a sinistra -->
<tolki-chat bot="..." position="left"></tolki-chat>

<!-- In basso al centro -->
<tolki-chat bot="..." position="center"></tolki-chat>
```

### Modalità inline

In modalità inline, la chat è incorporata direttamente nel flusso della pagina senza un pulsante di apertura.

```html
<tolki-chat bot="..." position="inline"></tolki-chat>
```

## Personalizzazione

Il widget è completamente personalizzabile tramite attributi HTML. Puoi controllare:

- **Layout** — Posizione, dimensione finestra, dimensione pulsante, margine
- **Comportamento** — Apertura automatica, espandibile, non chiudibile
- **Aspetto** — Modalità scura, bordi arrotondati, effetti backdrop
- **Colori** — Colori del pulsante e delle bolle messaggi
- **Contenuto** — Nome del bot, placeholder, messaggio di benvenuto, suggerimenti
- **i18n** — Lingua dell'interfaccia e lingue disponibili

Consulta la sezione [Attributi](/it/attributes) per il riferimento completo.

## Sistema di priorità

Gli attributi seguono una priorità a tre livelli:

| Priorità | Sorgente | Descrizione |
|----------|----------|-------------|
| 1 (massima) | Attributi HTML | Valori impostati direttamente nel tag |
| 2 | Backend | Valori dall'API Tolki |
| 3 (minima) | Default | Valori di fallback predefiniti |

Un attributo impostato via HTML sovrascrive sempre il valore del backend.
