Il widget `<tolki-chat>` comunica con l'API backend di Tolki. Di seguito gli endpoint principali.

## URL base

```
https://api.tolki.ai/chat/v1/embed/
```

## Impostazioni bot

Recupera la configurazione e le proprietà del bot.

```bash
curl https://api.tolki.ai/chat/v1/embed/{bot_uuid}/settings/{lang}
```

Restituisce il nome del bot, gli stili, il messaggio di benvenuto, i suggerimenti e tutte le proprietà configurate.

## Invio messaggio

Invia un messaggio dell'utente e riceve la risposta del bot.

```bash
curl -X POST https://api.tolki.ai/chat/v1/embed/{bot_uuid}/chat/{chat_uuid}/message \
  -H "Content-Type: application/json" \
  -d '{"message": "Ciao!"}'
```

Ogni elemento della risposta **deve** includere un campo `id`. Questo è necessario per l'endpoint di feedback.

```json
{
  "items": [
    {
      "type": "markdown",
      "id": "123",
      "content": "Ciao! Come posso aiutarti?"
    }
  ]
}
```

## Feedback messaggio

Invia un like o dislike per un messaggio specifico.

```bash
curl -X POST https://api.tolki.ai/chat/v1/embed/{bot_uuid}/chat/{chat_uuid}/message/{id}/feedback \
  -H "Content-Type: application/json" \
  -d '{"type": "like"}'
```

| Campo | Tipo | Descrizione |
|-------|------|-------------|
| `type` | `"like" \| "dislike"` | Tipo di feedback |

## Valutazione conversazione

Invia una valutazione di soddisfazione complessiva per la sessione di chat.

```bash
curl -X POST https://api.tolki.ai/chat/v1/embed/{bot_uuid}/chat/{chat_uuid}/rating \
  -H "Content-Type: application/json" \
  -d '{"rating": 5}'
```

| Campo | Tipo | Descrizione |
|-------|------|-------------|
| `rating` | `1 \| 2 \| 3 \| 4 \| 5` | Valutazione a stelle |

::callout{icon="i-lucide-info"}
Il widget gestisce automaticamente tutta la comunicazione API. Questi endpoint sono documentati solo come riferimento.
::
